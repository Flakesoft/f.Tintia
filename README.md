f.Tintia is a free and open-source color picker for Android. Simply open an image, tap any pixel, and instantly copy its color in HEX or RGB format.

Built with Flutter and designed with Material 3.

## Features

- Pick any color from an image
- Open images from your device
- Accurate pixel color detection
- Copy HEX values
- Copy RGB values
- Copy HSV values
- Copy HSL values
- Automatic light and dark mode
- Dynamic Color support on Android 12+
- No ads
- No tracking
- 100% Free and Open Source
